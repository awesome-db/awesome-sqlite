# Contribution Guidelines

Thanks for helping make this list better! Please follow these guidelines:

- Search existing entries to avoid duplicates.
- Add one link per pull request, in the most fitting category.
- Use the format: `- [Name](link) - Short description ending with a period.`
- Keep descriptions concise, factual, and free of marketing language. This list aims to be impartial.
- Note if a project is proprietary or has paid tiers.
- Only add actively maintained projects, or clearly mark them as archived.
- Keep entries in alphabetical order within a category, where practical.
- Check spelling and grammar.
- Make sure your pull request title is short and descriptive.
